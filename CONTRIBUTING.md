# Contributing to DuoForge (public beta)

Thank you for helping improve DuoForge! This repository hosts **public previews and experiments**, not the full production platform.

## Try before contributing

- [Play the beta games](https://duoforge-gaming.cuddlyelk8.chatgpt.site/games)
- [Explore the browser preview](https://mattd81.github.io/DuoForge-Preview/)
- [Try the 3D Studio preview](https://mattd81.github.io/DuoForge-Preview/workshop/studio/)
- [Browse open issues](https://github.com/MattD81/DuoForge-Preview/issues)

Features may be incomplete or different between the live platform and GitHub previews.

## Report bugs

Open an issue with:
1. A link to the affected game or preview.
2. Your device, operating system, browser and (if relevant) screen orientation.
3. Steps to reproduce, expected result and actual result.
4. A real screenshot or short recording **if you have one** (do not fabricate screenshots).
5. Console errors, if available, with tokens and personal data removed.

## Suggest improvements

Describe the player or creator problem, your proposed change, and a small acceptance test. For mobile UX, include portrait and landscape behaviour.

## Submit a pull request

1. Check existing issues and PRs to avoid duplicates.
2. Create a feature branch and make one focused, reversible change.
3. Include test steps and links to a working preview when possible.
4. Confirm desktop and mobile behaviour for changes that affect UI or gameplay.
5. Preserve credits and check all third-party asset, code and music licenses before adding anything.
6. Do not add secrets, user data or private production code.
7. Request review before merging; never merge solely to earn a GitHub badge.

## Areas where help is welcome

- Mobile layouts, touch controls and gamepad input.
- GLB importing, material handling and performance.
- Rendering quality, accessibility and reliable game startup.
- Documentation, reproducible bug reports and small tests.

## Community guidelines

Be constructive and respectful. Credit original authors and retain required license notices. Contributions should improve the project, not artificially inflate stars, pull requests or achievements.

**Note:** GitHub stars and achievement badges are voluntary and cannot be guaranteed. The best way to grow this project is to make the beta useful, transparent and easy to try.
