# Premium MakeHuman fighter integration

Replacing SDF toy-like proportions with a genuinely human base, faces, photo-based skin textures, and game-ready human joints and garments. Uses MIT [Ara 3D Gen](https://github.com/olatunde85/3d-gen), CC0 MakeHuman data (see Ara LICENSE and scripts/ASSETS_LICENSE.txt). Some animation clips are from CMU MoCap and should not be sold standalone. Credit CMU data origin where used.

This is an OPTIONAL CPU-only GitHub Pages build. No Work, external paid models, cloud GPU or Sites rebuild. New GLBs must actually generate and pass structural validation; a successful source push alone does NOT prove realistic rendering. The game prefers Ara assets but falls back to existing V3/V2 without breaking the playable link.

Ara revision pinned to 654a5d81fc828aba31d006e3fac3ed1eed5c857c. Prototypes need real in-browser/iPhone gameplay validation and art review before claims of AAA quality. The original DuoForge Sites project is not altered.
